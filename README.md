# 📊 Finance Analysis Dashboard (Bank Transactions)

A **Power BI dashboard** built to analyze and visualize **bank transaction data** with real-time insights into customers, transactions, and risk.  
This project demonstrates advanced data modeling, DAX calculations, and interactive reporting for financial analytics.

---

## 🚀 Features

- **Key Metrics Overview**
  - Total Amount, Transactions, Average Transaction Value
  - Total Fee & Total Tax with YoY comparisons

- **Interactive Visualizations**
  - 📈 Transaction trends by month
  - ✅ Transaction status breakdown (Success, Failed, Pending)
  - 👥 Customer segmentation (Retail, Premium, SME, Corporate, Wealth)
  - 🌍 Regional distribution by state
  - ⚖️ Gender-based transaction analysis

- **Detailed Transaction Type Table**
  - Bill Payments, Card Payments, Deposits, Withdrawals
  - Loan EMI, Investments, Refunds, Transfers
  - Each with **Total Amount, Fee, Tax, and Transaction Count**

- **Dynamic Filters**
  - Year, Occupation, Merchant Category
  - Clear All Filters option for quick reset

## 📈 Insights Highlight
- Majority of transactions are successful (~85%).

- Retail customers dominate transaction volume.

- Female customers slightly outpace male customers in transaction share.

- Loan EMI & Transfers contribute the highest transaction amounts.

- Regional hotspots include Maharashtra, Karnataka, and Gujarat.
